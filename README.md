Dashboard – License Management System

A modern and responsive License Management Dashboard built using React and Vite.

🚀 Features
Dashboard overview
License generation and management
Client management
License history
Sidebar navigation
Responsive user interface
🛠️ Technologies Used
React.js
Vite
Tailwind CSS
JavaScript
Lucide React
CSS
📦 Installation
Clone the repository:
bash
git clone https://github.com/Sourabh037/DashBoard.git

Navigate to the project:
bash
cd DashBoard

Install dependencies:
bash
npm install

Start the development server:
bash
npm run dev

Open the local URL shown in your terminal.
